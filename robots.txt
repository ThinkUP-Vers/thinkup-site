# ── Signaux de contenu (Content Signals) ────────────────────────────────────
# La ligne « Content-Signal » declare a quoi les robots ont le droit d'employer
# le contenu du site. Trois usages, chacun a « yes » ou « no » :
#   search    indexation et resultats de recherche (liens et courts extraits) ;
#             n'inclut pas les resumes generes par IA.
#   ai-input  contenu verse a un modele au moment de repondre : RAG, ancrage,
#             reponses generatives des moteurs de recherche.
#   ai-train  entrainement ou reglage fin de modeles.
#
# Les trois sont a « yes » sur l'ensemble du site : Think'UP cherche a etre cite
# dans les reponses des IA, pas a s'en proteger. Aucun droit n'est donc reserve
# au titre de l'article 4 de la directive (UE) 2019/790. Pour reserver un usage,
# passer le signal correspondant a « no ».
#
# Un signal absent ne vaut ni autorisation ni interdiction. Un robot ne lisant
# que le groupe le plus specifique qui le concerne, la ligne est repetee dans
# chaque groupe : placee dans le seul « User-agent: * », elle serait invisible
# pour GPTBot, ClaudeBot et les autres robots nommes ci-dessous.
#
# Ces lignes expriment une preference. Elles n'empechent techniquement personne
# de passer outre. Reference : https://contentsignals.org/
#
# Contexte pour les agents et les moteurs de reponse : https://think-up.fr/llms.txt
# Chaque page existe aussi en Markdown : meme adresse en .md, ou en demandant
# l'en-tete « Accept: text/markdown ».
